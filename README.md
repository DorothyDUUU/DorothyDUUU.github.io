# Academic Personal Homepage

This is the source code for my academic personal homepage, hosted on GitHub Pages.

## Structure

- `index.html` - Main homepage
- `style.css` - Styling
- `blog/` - Blog posts directory
- `files/` - PDF files, CV, etc.
- `images/` - Images and profile photo

## Local Development

Simply open `index.html` in your browser to preview locally.

## Deployment

This site is automatically deployed via GitHub Pages. Any push to the main branch will update the live site at https://DorothyDUUU.github.io

## Customization

1. Replace placeholder text in `index.html` with your information
2. Add your profile photo as `profile.jpg` in the root directory
3. Update publications, research projects, and blog posts
4. Modify colors in `style.css` by changing the CSS variables in `:root`
